# 初始测量资料说明

lab-samples 由独立台架测试生成，单位均为 µg/m³。样本很小，不足以证明所有环境的总体置信区间。Reference 的高湿检验来自与 Echo brochure 不同的试验来源。

Echo 厂商 brochure 声称 RH 20–95% 下不确定性 ±2 µg/m³；现有 Echo lab samples 仅覆盖 RH40–60%。采购人员摘要引用该 brochure，不是另一项独立测量。

两个型号混用时需要事前交叉校准、统一时间基准、数据完整性和异常质量检查；原始量纲必须先统一。设备报价没有包含 costs.csv 中的现场固定成本。

电池套件足以覆盖 14 天观测且兼容两种型号（本场景既定工程事实）。Reference 离线存储足以容纳全部观察；Echo 没有离线存储，需要稳定网络或外置 logger。安装与校准最多三天，等待设备与安装可以先后计入时间计划。
