# 非专家用户验收脚本

环境、包版本、安装制品 hash：

1. 干净环境安装并 doctor；正常创建/加载项目。
2. 只说“继续这个项目”，检查是否展示当前事实与未决事项。
3. 引入合法外部候选；不告诉 Agent 正确下一步。
4. Agent 提出有来源的行动；用户通过正常 review 确认或拒绝。
5. 执行与接受结果，检查候选/正式状态是否清楚。
6. 正确负面发现是否保留，业务目标是否仍明确 unmet。
7. 开一个新的 Session 继续，不给旧 transcript。
8. 按需一次独立协作；记录它对后续行动的实际影响。
9. 中断/重复/迟到事件后状态是否可理解且无双效果。

记录用户为操作产品而额外做的工作：是否查SQL、写一次性JS、猜Tool Mode、手动修复路径、手工拼TaskSpec。必要批准不等于多余干预。
