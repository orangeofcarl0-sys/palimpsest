# 真实 Agent 行为审查

Run / cohort / condition / model / code freeze：

## 有效性

是否真实模型、是否污染、初始 prompt 是否泄漏答案、time window、实际工具/权限、Operator 是否代办。

## 时间线

| 时间/seq | Actor | 行为 | 实际对象 | 结果地位 | 下一步影响 |
|---|---|---|---|---|---|

## 分项观察

发现；source standing；推理；独立来源；Proposal；Authority；Work；验证；结果交付/消费；canonical接受；新Session继承。

## 摩擦与成本

重复查询、模式误用、Bash/SQL/源码探索、失败恢复、人工改写、active/wait time、input/output/cache、费用是否已知。

## 结论与归因

哪些行为成立；哪些只是提到；是否 co-cause；缺失反事实；不能作出的结论。
