## Site A — Marsh Lane Store

Unheated store. Design minimum temperature **-12 °C**. Door access 1.2 m. No coastal exposure.

## Site B — Harbour Workshop

Coastal and flood-exposed. Design minimum temperature **-4 °C**. A **coastal-rated warranty is
mandatory**.

## Site C — School Annexe

Listed building. Ambient minimum **2 °C**. The unit must be **no wider than 800 mm**. Installation
is only possible in the May–June window.
