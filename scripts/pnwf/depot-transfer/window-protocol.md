# R4 当班上限与窗口利用率

冻结基线、业务提示、车辆窗口及评分器沿用 R4。23:40 测量已包含本班冷夜负荷和预约平移；两车时窗、四格半小时及 20 kW 平移匹配时，以该记录给出的逐格可用交流功率取代旧推算。变更工况须重新确定适用记录。本工单要求高效工况最大可用充电量，冻结车辆在这些窗口均有足够电池容量接收全部可用功率。

两组共享签发工具说明、适用条件和拒签结果。逐格列出超限或未用的功率；原表同时存在两者，优先返回超限并展示未用窗口。保持原样的测量工具只返回送测 SHA 的结果。签发与十项独立业务评分分别记账。受保护的旧文件、合法引用与候选 SHA 的要求沿用原契约。

Mock 先签超限草案，再签合法但少排的草案，均须看到拒绝，再以原回执签发窗口已用足的版本并通过业务评分。仅在两组 Mock 通过后按 P、F 顺序运行普通 DSH。业务目标不提供求证指令。每场含复核最多 64 笔、30 分钟、单请求 240 秒，按量记账，无金额和总 token 上限。新 UNKNOWN 停止后序准入。

区分档案已有的上限、签发工具首次显示的缺额、模型显式计算或改表、维护者回执与放行单落笔。检查工作区草稿和提交顺序；仅回传给定版本的电量不足以证明维护者发现了更优班表。复核请求、用量和交付后续变化单列。旧判分与旧 UNKNOWN 原样保留。
