# R7 请求功率签发契约

P、F 从同一冻结 R7 基线开始。提示原文、工具能力、私有车端模型和十项业务评分沿用上轮。按 P、F 顺序运行。独立会话的上限为 64 笔、30 分钟，单笔等待 240 秒，维护者共用该窗口。金额和总 tokens 按量。新 UNKNOWN 关闭后续准入。

签发以完整候选 SHA 的四格请求与已归档的 23:40 时段上限为准。回执逐格列出请求、上限、限幅后的实际功率和超限幅度。出现正超限量时，候选可以作为试件提交，宿主拒绝签发整张工单。维护者测得的车辆净量独立于功率门禁。本席 21:00 复测只说明旧工况。

两席均可对当前提交调用 depot_release_check 取得可操作的拒绝。在 P 的 DELIVER 和两席的最终归档处复核同一门禁。F 自然退出时宿主检查已提交的工单；P 另须有实际 DELIVER。签发状态、独立业务分、逐车决定和自然退出分别记录。按调用 ID 区分测量回执中的拒签理由、显式签发检查、实际修改及重试；只计模型收到的结果为反馈。对比两份历史 6/10 原稿与新提交。
