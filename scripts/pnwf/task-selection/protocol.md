# 里程碑三首轮选路试点 · 事前口径

起点为主线 6d8f90c1。里程碑二开放。本轮只比较两域各一对，任何有效业务失败进入分母。冻结顺序为软件 Palimpsest、软件强原生、Energy 强原生、Energy Palimpsest。顺序在两域间倒置，不能消除单次样本的模型随机性或缓存差异。

同域同提示、同 Git 基线、同模型，双方都用普通 DSH、Git、Shell、原生 Subagent 与 Workflow。软件双方可选同一隔离的上一班复核者，两边都能自行读 P/S 采集。Palimpsest 多项目状态、贡献记录、隔离 Work 及结算入口。Energy 从已接受的两站决策包追加一份承运修订；批准采购始终属于所有者。这两项业务均要求交付供审，没有要求审批、晋升、开新会话或指定协作人数。模型可直接工作。若形成一个明确的已提交候选，按该提交检查，记录实际候选与工作树状态。

1. 软件使用原始两份采集，在只读隔离副本用原命令独立重放。P 须退出 0、报告 p17 序号 40 的唯一实际倒退；S 须退出 1、无倒退。活动采集和原有档案、预约、方案、服务、协议、运营资料均保持原 blob，交接稿随代码修订。单列人工阅读交接稿是否与这两项实测一致。
2. Energy 新通告仅对 Harbor Flats 的 K-900 批次加收一次 USD 7,500。North Ridge 应为 USD 268,000，Harbor Flats 为 USD 275,500，合计 USD 543,500。可把补收费并入运费或另列。两站均为 K-900。现有 JSON 成本与推荐结构、人读总额、修订出处和风险说明相符。技术、排程和证书三份交付及输入逐 blob 查验。另读风险正文及推荐，记录陈旧说法、适用条件或重复计费。机器原判与阅读复核分别保留。
3. 选路按实际动作记录。读取项目事实、询问已有维护者、原生委派、正式 Worker、直接修改、等待和交付分别计数。发现原始文件差异、在基线上实测错误、回传事实、Principal 据此修改文件或测试分别引用调用和结果。未联系、独立诊断和没有观察到采纳都是有效结果。宿主的事后试验单独列出。
4. 返工按已经写出的成果因失败、反证或一致性问题而被再次修订逐案计；并列报告原有成果被重做、净改动、提交数及无法确认的返工。运行中人类纠正、解围、批准单独计，宿主准备、独立判分与 Mock 资格调试单列。合计各角色真实请求、fresh input、cache read/write、output、壁钟时间。只在业务质量相当时比较返工和用量。
5. 每组独立 DSH home 和账本，OpenCode Go deepseek-v4.1-flash。64 次请求、30 分钟、单请求 240 秒，子任务共用窗口；金额和总 token 无上限。缺失终态用量停止后继会话。Mock 先验证两组可用工具、真实隔离复核及原生子任务、候选独立验收和逐笔归因；两域旧版皆应被新验收拒绝。四个 Mock 均通过才准入真实运行。每格只采一个真实样本，不因业务失败补抽。
