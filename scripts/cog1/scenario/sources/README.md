# Riversdale Community Arts Centre — planning pack

> **SYNTHETIC MATERIAL.** Riversdale Community Arts Centre is fictional, and every
> record in this pack was written for a research exercise. It does not describe any
> real institution, and it contains no personal data.

All records cover the same fictional venue and its 2024–2025 season.

| file | contents |
|---|---|
| `attendance.csv` | monthly sessions, visits and unique participants per programme |
| `survey.md` | the 2025 visitor satisfaction survey, its method and its raw tables |
| `interviews.md` | four stakeholder interviews, lightly edited |
| `constraints.md` | operating constraints: licence, building, staffing, season |
| `resources.md` | the quarter's resource envelope and the unit costs quoted to the trust |
| `prior-interventions.md` | two earlier interventions and what happened afterwards |
| `open-questions.md` | questions the trust board asked and has not answered |
